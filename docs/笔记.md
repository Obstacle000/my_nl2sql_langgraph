## 账号
### 1. jwt双层拦截
**第一层**
1. 续签机制
>10:00 登录 → 签发 token A（exp=12:00）  
11:50 请求进来 → 剩余 10 分钟 < 15 分钟阈值  
      → 中间件用 A 里的 user_id/username 再签 token B（exp=13:50）  
      → 响应头 X-New-Token: B  
      → 前端把 A 换成 B  
12:00 A 过期，但前端早就用 B 了 → 用户没感觉  
2. 用户数据传入上下文,所有请求放行  

代码:
```python
@app.middleware("http")
async def auth_middleware(request: Request, call_next):
    """第一层：解析 token → ContextVar；快过期则续签。

    这一层永不拒绝请求：是否允许访问由第二层（每个路由的 user_id: CurrentUser）决定，
    这样公开接口也能在带 token 时享受续签。
    """
    request_id_ctx_var.set(uuid.uuid4().hex[:8])
    user_id_ctx_var.set(None)
    new_token: str | None = None

    auth = request.headers.get("authorization", "")
    if auth.startswith("Bearer "):
        try:
            payload = decode_access_token(auth.removeprefix("Bearer ").strip())
            user_id_ctx_var.set(int(payload["sub"]))
            if int(payload["exp"]) - int(time.time()) < REFRESH_THRESHOLD_S:
                new_token = create_access_token(int(payload["sub"]), payload["username"])
        except Exception:
            # 解析失败按未登录处理，不在这里拒绝
            pass

    response = await call_next(request)
    if new_token is not None:
        response.headers["X-New-Token"] = new_token
        response.headers["Access-Control-Expose-Headers"] = "X-New-Token"
    return response
```
**第二层**  
  
对需要拦截的请求,带上参数`user_id: CurrentUser,`进行依赖注入  
不带意味着是公共接口

代码:
```python
def get_current_user_id() -> int:
    """第二层：从第一层写入的 ContextVar 读 user_id；为空即未登录。"""
    user_id = user_id_ctx_var.get()
    if user_id is None:
        raise UnauthorizedError("登录已失效，请重新登录")
    return user_id


CurrentUser = Annotated[int, Depends(get_current_user_id)]
```

**实现**  
这个项目没有`port`抽象,`AuthService` 直接依赖具体类；**事务在仓储里提交，服务层不碰 session**  
```python
class AuthService:
    def __init__(self, user_repo: UserRepository) -> None:
        self.user_repo = user_repo

    async def register(self, username: str, password: str) -> dict[str, str]:
        if await self.user_repo.get_by_username(username) is not None:
            raise ConflictError("用户名已存在")
        # create_committed 内部 async with session.begin() 提交
        await self.user_repo.create_committed(username, hash_password(password))
        return {"username": username}

    async def login(self, username: str, password: str) -> dict[str, str]:
        user = await self.user_repo.get_by_username(username)
        if user is None or not verify_password(password, user.password_hash):
            raise UnauthorizedError("用户名或密码错误")
        return {
            "access_token": create_access_token(user.id, user.username),
            "token_type": "bearer",
        }
```

| 执行 | 只允许查本数据集登记过的表 | 只允许 SELECT + `fetchmany(limit)` |

### 5. 建索引：MySQL 是事实源

```python
async def reindex_dataset(self, user_id, dataset_id, datasource_id=0) -> int:
    # ① 先删旧向量（每次 upsert 用新 uuid，不删会累积重复）
    await self.qdrant.delete_by_dataset(COLUMN_COLLECTION, user_id, dataset_id)
    # ② 从 MySQL 读字段
    columns = await self.meta_repo.list_columns(dataset_id, datasource_id)
    # ③ 描述 + 每个别名 → 向量 → Qdrant
    for col in columns:
        for text in [col.description or col.name, *col.alias]: ...
    # ④ 样例值 → ES
```

```text
· 一个字段 = 1 条描述向量 + N 条别名向量
  point_id 各不相同（否则互相覆盖），payload.id 相同 → 检索后按 id 去重
· 先写 MySQL、再 reindex：索引失败可重试，也能换 embedding 模型重算
· 调用点：上传 CSV 后 / 建 MySQL 源后 / 同步后
```

